# 🌐 Personal Portfolio Web Application

A responsive and interactive personal portfolio website developed as part of the **Full Stack Development Assignment-1**.

The portfolio showcases my profile, academic background, technical skills, projects, achievements, and contact information using modern web development technologies.

---

## 📌 About the Project

This project is a personal portfolio web application designed using:

- HTML5
- CSS3
- Bootstrap
- JavaScript (ES6+)

The website is designed to be responsive, accessible, visually consistent, and interactive across different screen sizes.

---

## ✨ Features

- 🏠 **Home** – Introduction and profile section
- 👩‍💻 **About** – Personal introduction and background
- 🎓 **Education** – Academic qualifications
- 🛠️ **Skills** – Technical skills and technologies
- 💻 **Projects** – Showcase of completed projects
- 🏆 **Achievements** – Certifications and achievements
- 📩 **Contact** – Contact form with client-side validation
- 🌙 **Theme Switching** – Light and dark mode
- 🔍 **Project Filtering** – Filter projects by category
- 📱 **Responsive Design** – Works on desktop, tablet, and mobile devices

---

## 🛠️ Technologies Used

### Frontend
- **HTML5** – Semantic webpage structure
- **CSS3** – Styling, layouts, animations, and responsive design
- **Bootstrap** – Responsive grid, navbar, cards, buttons, and forms
- **JavaScript ES6+** – Interactivity and DOM manipulation

### Other
- Bootstrap Icons
- Git
- GitHub
